# 💰 Python Expense Tracker

A simple **terminal-based Python project** for recording and tracking
daily expenses.

## ✨ Features

-   ➕ Add an expense
-   📅 Validate date (`DD-MM-YYYY`)
-   🏷️ Add category and description
-   💵 Enter expense amount
-   📋 View all expenses
-   🧮 Calculate total spending
-   🚪 Exit the application

## 🛠️ Technologies

-   Python 3
-   Lists & Dictionaries
-   `if-elif-else`
-   `while` & `for` loops
-   `input()` & `print()`
-   `try-except`
-   `datetime`
-   F-strings

## ▶️ Run the Project

Make sure Python is installed:

``` bash
python --version
```

Run the application:

``` bash
python main.py
```

## 🖥️ Menu

``` text
1. Add Expense
2. View All Expenses
3. View Total Spending
4. Exit
```

## 📅 Date Format

Enter the date as:

``` text
22-09-2026
```

Invalid dates such as `31-02-2026` are rejected.

## ⚠️ Limitation

Expenses are stored only while the program is running. Data is lost when
the application closes.
